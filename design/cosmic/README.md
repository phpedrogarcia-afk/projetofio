# Acervo visual cósmico do Fio

Este diretório preserva o material visual do tema **Céu Noturno**. Nada aqui é recurso de runtime Android, nem está integrado ao aplicativo. A entrada, alteração ou remoção de arquivos deve preservar os bytes originais e atualizar o manifesto.

## Classes

- **SOURCE ASSET**: candidato a adaptação futura, ainda sem autorização de integração.
- **VISUAL REFERENCE**: estabelece material, composição, paleta ou atmosfera; não deve ser usada literalmente.
- **CONCEPT BOARD**: prancha exploratória. Textos, layouts ou funcionalidades nela não são contrato de produto.

## Cosmic visual grammar

| Conceito | Linguagem visual |
| --- | --- |
| Memória | planeta ou corpo celeste |
| Tempo | órbita |
| Orientação temporal | bússola ou astrolábio |
| Algum dia | infinito |
| Lacrar | chave e selo |
| Lacrado | selo temporal ou planeta protegido |
| Favorito | estrela |
| Fixado | marcador ou âncora |
| Privacidade | cadeado ou selo |
| Busca / Home / Arquivo / Ajustes | lupa / casa / arquivo / engrenagem convencionais |
| Interface | smoked mirrored glass |
| Atmosfera | céu, nebulosa e estrelas |
| Tempo ancestral | observatório ou pirâmide em line-art |

Símbolos familiares permanecem em funções familiares; a linguagem própria do Fio é reservada a conceitos próprios. O conteúdo autobiográfico sempre vence a decoração.

## Contrato de planetas e estados

As únicas quatro bases visuais são **Semente** (neutra), **Dourado** (destaque explícito), **de Anel** (órbita longa) e **Velado** (protegido). Elas são variações visuais, não diagnósticos emocionais: cores nunca devem inferir o estado psicológico da pessoa.

**Lacrado**, **Favorito** e **Fixado** são estados independentes que se sobrepõem a uma base. Lacrado significa conteúdo inacessível até a condição ou data futura; não é o mesmo que Selada, que diz respeito à privacidade. Favorito é sempre uma marcação explícita da pessoa; Fixado é acesso rápido.

A chave/lacre preferida para eventual uso funcional é minimalista, dourada e legível em tamanhos pequenos. As versões monumentais são apenas referência.

## Camadas canônicas

`Z0` base cósmica profunda → `Z1` nebulosa/névoa → `Z2` estrelas → `Z3` planetas → `Z4` line-art celeste → `Z5` observatório/pirâmide line-art → `Z6` vidro → `Z7` interface funcional → `Z8` tipografia e conteúdo → `Z9` destaques dourados/estados.

## Limites desta ingestão

Este acervo não autoriza implementar planetas, lacre, favoritos, fixação, animações, novas telas, calendário, novo Guardar ou mudanças de navegação. Em especial, a possível direção futura de simplificar a navegação para Home, Guardar, Arquivo e Ajustes — e considerar Encontrar dentro de Arquivo — está registrada apenas como **PRODUCT DIRECTION — NOT IMPLEMENTED**.

As pranchas de Home podem conter dashboards, métricas, cards, gráficos ou destinos que não foram aprovados. Nenhum deles deve ser inferido como feature.
